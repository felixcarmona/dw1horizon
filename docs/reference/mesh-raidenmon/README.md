# Raidenmon 336: exhaustive measurements and partial repair

This work does **not** complete the requested all-pair clearance or establish
unrestricted repair floors. Five of 62 crossing bone pairs clear globally;
57 remain. Every remaining pair has its measured depth and witness in
[pairs.md](pairs.md), explicitly marked **floor unproven**. Joint adjacency and
hidden surfaces are retained in the detector; neither is used to excuse a pair.
The earlier ±8-unit translation certificates are not reused as repair limits.

The baseline is the final round-five output at `integ5`. Both complete ledgers
cover all 51 occupied slots and 1,684 decoded frames, including aliases,
adjacent parts, both penetration directions, and the GPU quad diagonal.
before-frames.csv.gz (regenerated by `python3 -m tools.models.mesh_raidenmon_review`; output kept under `build/`) and
after-frames.csv.gz (regenerated by `python3 -m tools.models.mesh_raidenmon_review`; output kept under `build/`) record every crossing frame;
[the audit](audit.json) records pair maxima, witnesses and preservation checks.
Depth is the existing symmetric edge/triangle measurement, not overlap volume
or a count of visible defects.

The new model-specific final pass opens the right claw shoulder by
(−15°, −15°, −30°), retaining the original rotational motion. Its independent
slot 61 instead receives (−60°, 0°, −15°). All claw/finger contacts with foreign
parts clear throughout that clip. Slot 43's left upper arm follows a smoothstep
roll/yaw detour, followed by a small pitch correction: it clears the left
forearm against every non-adjoining part throughout all 47 frames. This includes
the reported calf pair, **123.206 → 0 units in slot 43**. That bone pair still
reaches **66.325 units in slot 36 frame 12**. Its global maximum must not be
reported as zero.

Globally cleared pairs are 3/4, 12/18, 13/17, 13/18 and 14/17. Forearm/thigh 3/20
falls 139.213 → 63.014 units, claw/ankle 11/17 falls 84.998 → 38.416, and
claw/foot 11/18 falls 84.107 → 51.804. No new crossing bone pair appears. The
only increased global maximum is existing shoulder/upper-arm pair 9/10,
63.368 → 63.514 units (+0.146). The largest retained crossing is torso/backpack
1/9, 137.627 units in slot 43 frame 22. All 57 residuals remain unresolved.

Whole identical local-coordinate vertex and normal pools now share immutable
TMD storage. Object counts, joint matrices, oriented triangle corners, UVs,
materials, colors, normals and primitive order remain exact. This saves 888
vertex bytes and 184 normal bytes inside this model. Animation costs 62 bytes;
resident size falls **72,646 → 71,636 B**. Cold reads fit. Packet-format bytes
are unchanged. Every other provider pin is unchanged, so the resident peak
remains **100,256 / 100,352 B**. Root travel, events, timing, loops, scales,
translations, binding indices and aliases are checked across all 1,684 frames.
Only the documented local rotations differ. Only the canonical 336 model pin
changes, through the scoped repository pin tool; its texture pin is unchanged.
Fresh source/delta/provider verification passes 1/1.

PSX-rule renders cover **every frame**, eight azimuths at 30° elevation, before
and after, and two OT-bin phases: **53,888 images** at 128×128. Each clip/view
uses one common scale and bounds for both models; the diagnostic camera follows
only their unchanged root translation. The renderer retains first-triangle
quad culling, the GPU diagonal, four-unit OT bins, reverse insertion within
ties, affine textures, zero-color discard, STP and all four blend equations.
The model-specific native audit rasterizer matches the Python reference at
**230 actual-model cases with zero differing pixels**; synthetic tests also
cover bent quads, ties, transparency and all blend modes. This helper changes
no runtime renderer. These remain orthographic offline measurements, without
GTE perspective, integer GPU raster precision or runtime confirmation.

Render measurements (regenerated by `python3 -m tools.models.mesh_raidenmon_review`; output kept under `build/`) retain every frame/view. The worktree's
`build/renders-all/SLOT.npz` files contain all four image states, with corresponding
JSON camera frames and metrics. Changed pixels total 7,916,776. Pixels sensitive
to a two-unit OT phase shift total 74,749 → 74,602. Temporal pixel differences
include normal movement; neither phase sensitivity nor temporal differences
establish visible popping or a repair floor. The broad sampled detector still
flags part interpenetration and retains 42 candidates; its native envelope
passes, as it already did before this work.

[Rejected experiments](experiments.json.gz) retain constant arm searches,
per-frame left-arm options, shell rotation gains, and shell offsets out to
64 units. Smaller constant left-arm corrections clear the legs but reintroduce
forearm/plate contact mid-clip. Flattening shell motion or moving whole shells
creates additional forearm/calf contacts. Global claw trials that introduce
new torso/finger or shell/finger pairs are rejected. These are finite trials,
**not** proofs against reshaping, rebinding, larger poses or re-derivation.

Validation: the related suite runs 105 tests, with 102 passing and three private
fixture cases skipped. Seven Raidenmon-specific tests also pass after the final
rasterizer test expansion. Changes are uncommitted; no push or PR was made.
