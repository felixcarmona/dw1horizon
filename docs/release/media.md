# Publication media

The tracked site contains only `web/media/disc.svg`, the project's authored disc
placeholder. Pages copies tracked assets, excludes local clips and renders feature
cards without missing media. No box art, gameplay recordings or console photo is
included in this reviewed snapshot.

Historical local hosting used libretro-thumbnails PlayStation box art, local
gameplay captures and a console photo attributed to Evan-Amos (Wikimedia Commons,
PSX-Console-wController.png). Neither a thumbnail source nor capture ownership
establishes permission to redistribute game artwork. These external files and the
current server were not audited by this source review; omit them from public
artifacts until their exact bytes, source, permission and required attribution
have been reviewed and inventoried. The historical public-domain photo claim
applies only to that named photo and must be verified against the supplied file.

Adding a tracked media file changes the publication inventory. Record its path,
checksum, author/source, permission and notices here before building the site.
