# postgame

The post-game's Machinedramon stations (the fortress room 47, the mansion basement 66, the ice hall 104) and the Back
Dimension portal stay as in the original on every branch: a broken root changes the land above, not the curse. There is
no story source here; `arcs/summit/old-saves.py` restores the portal on 0.0.2 saves that lost it.
