# summit

There is always a rescuer at the summit, and every ending runs the game's reward tail (MetalGreymon, Airdramon and Devimon
join, seven prosperity, the portal). Ending 4.4 ("nobody comes") is gone: it needed a dead Airdramon. Endings differ in
Jijimon's farewell lines and in the key chain's ceremony.

`old-saves.py` recovers what a 0.0.2 save lost, on the next arrival in File City: the 4.4 rewards, a portal cleared by the
old "no curse" handler, Airdramon, and a Myotismon taken away by the newspaper. A save still on the way up with the old
flag gets Birdramon or Angemon as rescuer if they have joined, otherwise Airdramon.
