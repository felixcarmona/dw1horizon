# Galleries gates

`drain.py` preserves the original Whamon or town-reopened entry to the Sewer.
`rubbish-mouth.py` preserves the original northern road unlocks at Trash Mountain.
Both use step triggers on the new-map side and leave the mineward retreats open.

See the [world audit](../../../../../docs/mods/world-audit.md) for conditions,
legacy-save behavior and regression checks.
