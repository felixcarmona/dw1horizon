# Clearing

The Root Clearing (screen 314) has two Goblimon whose fights have a 25% Blue apple reward.
On each entry its ground spots roll independently: Deluxe mushroom 2%, Digimushroom 25% and 15%,
and Blue apple 30%. Each spot can be picked once per day; midnight resets it.
The clearing owns these spawns because its NPC script replaces the borrowed forest script.
The apple uses stable pickup ID 499 on the west side of the floor, away from both Goblimon.
