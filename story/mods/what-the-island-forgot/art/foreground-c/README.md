# Foreground cut-outs, screens 346–357

RGBA crops of each screen's own generated background art. RGB is copied unchanged;
only alpha selects the foreground silhouette. No original disc images are stored.

The matching per-screen manifests and tile ledgers live in `maps/foreground-c`.
Recreate or verify these crops with `maps/author/foreground-c.py`; the map builder
packs their masks using the finished background palette into existing donor TIMs.
