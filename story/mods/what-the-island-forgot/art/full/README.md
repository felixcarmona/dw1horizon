# Full-resolution entrance artwork

`seam-1-entrances.png` and `seam-2-entrances.png` are the source scenes for the
Seam entrance layouts. The matching scripts in `maps/author/` prepare the map
artwork, and `maps/foreground/seam-1.json` and `seam-2.json` reference these scenes
for foreground pieces. Game textures and other build outputs go under `build/`.
