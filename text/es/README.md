# Spanish translation

This is our authored Spanish translation from our English translation.
`dialogue/` holds script utterances by key; `names.json` holds executable strings
and names. Paging metadata controls how utterances fit into dialogue boxes.
The build reports missing translation keys in its text fallback report.

See [translation tools](../../docs/mods/translating.md) and
[game languages](../../docs/mods/language.md). Review records and translation
process notes are excluded from this repository.
