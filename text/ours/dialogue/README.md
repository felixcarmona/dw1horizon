# text/ours/dialogue

One JSON file per zone of `story/base/zones` (`file-city.json`, `native-forest.json`...; `maphead.json` for MAPHEAD's
keys `m<section>.*`), each `{key: our sentence}` for the utterances and menu options of that zone's scripts. Keys and
workflow: [translating](../../../docs/mods/translating.md). The English text's
scope and fallback behavior are described in [the translation overview](../README.md).
