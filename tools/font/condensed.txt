; Condensed lowercase of the mod executable's font, for long species names only (docs/mods/font.md "Long names").
;
; A name too wide for its field even with 1 pixel between letters (HerculesKabuterimon, MetalGreymonVaccine in the
; status screen's 120-pixel field) is drawn with these letters: 5 columns instead of the original's 6, the same rows
; (x-height rows 3-8, baseline row 8, ascenders from row 0, descenders to row 10). Capitals, digits, punctuation and
; the letters already 5 columns or narrower (f i j k l) keep the original glyph.
;
; Each glyph: a line "glyph CHAR" and 11 rows of up to 12 columns, '#' = ink, '.' = blank. No advance: the long-name
; drawing places each glyph by its ink (font.c drawStringMode). Order does not matter (no codes are assigned).
;
; After editing: python3 tools/fontgen.py condensed-header build/decomp-int/src/main/font_condensed.h, rebuild;
; `fontgen.py fit "HerculesKabuterimon" OUT.png` previews the three ways a name can be drawn.
