; Extra glyphs of the mod executable's font (docs/mods/font.md).
;
; Each glyph: a line "glyph CHAR WIDTH" and 11 rows of up to 12 columns,
; '#' = ink, '.' = blank. The Nth glyph in this file (from 0) is the
; Shift-JIS code F040+N (F07E, then F080 after skipping F07F): never reorder
; or delete glyphs, only append, or texts already assembled change letter.
;
; Metrics of the original font (GLYPH_DATA in font.c), to match:
;   capitals and digits: rows 0-9 (baseline row 9), 9 columns, width 12
;   lowercase: x-height rows 3-8 (baseline row 8), ascenders from row 0,
;              descenders to row 10, 6 columns, width 8 (i, l: 4; f, j: 6)
;   accents: lowercase rows 0-1 with row 2 blank; capitals have no room
;            above them, so accented capitals use a 7-row body (rows 3-9)
;   width: the advance in pixels. Ink must stay at least 2 columns inside it
;          (columns 0..WIDTH-2), and the game places glyphs on a 4-pixel grid
;          (drawGlyph uploads x/4), so 4, 8 and 12 are the safe widths.
;
; After editing: python3 tools/fontgen.py header build/decomp-mods/src/main/font_extra.h
; and rebuild the mod executable; `fontgen.py sheet OUT.png` previews them.
