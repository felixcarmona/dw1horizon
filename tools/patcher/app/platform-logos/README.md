# The Make buttons' logos

The pictures on the patcher's Make buttons (`tools/patcher/gui.py`): `disc.png` (PlayStation), `apk.png` (Android),
`setup.png` (Windows), `mac.png` (Apple) and `linux.png` (Tux), 40 x 40.

They are icons from [Bootstrap Icons](https://icons.getbootstrap.com) (`playstation`, `android2`, `windows`, `apple`,
`tux`), MIT licence, copyright (c) 2019-2024 The Bootstrap Authors, drawn in each brand's colour. The logos and names
are trademarks of their owners and are used only to name the system each file is for.
