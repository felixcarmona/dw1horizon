# content/

Game data we author, as opposed to code (`tools/`), story (`story/`) and engine patches (`mods/`).

| folder | what |
|---|---|
| `species/` | one JSON per Digimon species, complete: the 180 of the disc (0..179, with the mod's changes) and the imported ones (180..1023); names, level, techniques, drops, raise data, voices, battle music, model and texture, evolution (imports, provisional). `tools/species.py` reads them (the executable's tables, `DIGI.DAT`); `species.py extract` makes the originals' from your disc (`docs/mods/species.md`) |
| `balance/` | balance changes as JSON for the tables that are not per species (techniques, learning, items, tournaments, brain training, type factors, evolution items, join chances, wild Digimon): `*.json` overrides, `engine/tables.json` (the originals' evolution rows the C patches change, generated by `tools/balance.py sync`), `examples/` (with `examples/species/`). Species values are in `species/` (`docs/mods/balance.md`) |
| `techniques/`, `items/` | one JSON per technique and per item (numeric data and names) |
| `tables/` | the other gameplay tables as JSON (battle formulas and rules, care, clock, evolution rules, economy, fishing, join chances...) |
| `maps/`, `screens/` | one JSON per map file (its placed Digimon: species, position, moves, AI, path) and per screen (its file, texture counts, sound bank, flags) |
| `models/` | generators and specs of the partner and NPC models we build (cut from other games or made procedurally), one folder per merged feature; see its README |
| `imports/` | frozen source-disc import recipes and release mappings; player replay verifies the source files before conversion |
| `modeldelta/` | authored model edits as plain copy/add deltas applied after source-disc conversion |
| `record-originals/` | replay specifications and deltas for edited original species; the player's discs supply the models and textures |
| `localized/` | sign cutouts and tournament banner deltas for eight languages, reconstructed over the player's textures at build time |
| `icons/` | our 16x16 menu icons, one text file per species id (`tools/portraits.py` `load_drawn`): a palette and four frames (idle, idle 2, attack, hurt), drawn by hand; see [THIRD-PARTY.md](../THIRD-PARTY.md) |
| `sound/house-theme/` | our own song and instruments for FAALL.VHB's font 34 (Jijimon's house): `canon.mid` (Pachelbel's ground, public domain), `pad.wav` and `bell.wav` (synthesized); made by `tools/dws/audio_sources.py`, committed so the bank does not depend on the machine's floating point (`tools/derive` sound step; `--checks` says when the generator no longer makes them) |

**Policy.** Numeric gameplay data (species, techniques, items, tables, maps and screens) is committed as JSON. Models,
textures, sounds, dialogue text and disc files of the original game never are: the build reads them from your own disc.
